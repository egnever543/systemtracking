Referência de API

Todos os endpoints disponíveis, parâmetros e exemplos de resposta.

Autenticação: todos os endpoints /api/* exigem sessão autenticada (cookie session). O endpoint de rastreamento /r/:siteId é público.
GET /r/:siteId público

Registra um clique e redireciona para o WhatsApp. É o link que vai nos botões do site.

Parâmetros de URL

ParâmetroTipoDescrição
siteIdstringID do site (obrigatório)
fbclidstringClick ID do Facebook — capturado automaticamente
gclidstringClick ID do Google — capturado automaticamente
utm_*stringQuaisquer parâmetros UTM — todos capturados

Resposta

302 Redirect para a URL do WhatsApp com a mensagem pré-preenchida contendo o ID de rastreamento.

Exemplo

GET /r/abc123?fbclid=IwAR...
GET /api/events/lookup/:trackingId

Busca os dados de um clique pelo ID de rastreamento.

Parâmetros de URL

ParâmetroTipoDescrição
trackingIdstringEx: WA-8F3K2P

Resposta 200

{
  "id": "uuid",
  "trackingId": "WA-8F3K2P",
  "siteId": "abc123",
  "siteName": "Loja Principal",
  "fbclid": "IwAR...",
  "pageUrl": "https://meusite.com/pagina",
  "createdAt": "2024-01-15T14:32:00.000Z",
  "jaConvertido": false
}

Erros

StatusDescrição
404ID não encontrado
POST /api/conversions

Registra uma venda e envia o evento Purchase ao Facebook CAPI.

Body application/json

CampoTipoObrig.Descrição
trackingIdstringsimID do clique (ex: WA-8F3K2P)
valuenumbersimValor da venda (ex: 297.00)
currencystringnãoMoeda ISO 4217. Padrão: BRL

Exemplo de requisição

POST /api/conversions
Content-Type: application/json

{
  "trackingId": "WA-8F3K2P",
  "value": 297.00,
  "currency": "BRL"
}

Respostas

StatusDescrição
200Conversão registrada e enviada ao Facebook com sucesso
207Salvo no banco, mas o Facebook CAPI retornou erro — campo erro traz o detalhe
404ID de rastreamento não encontrado
409Este ID já foi convertido anteriormente
422Site sem Pixel ID ou Token da API configurados

Resposta 200

{
  "sucesso": true,
  "convId": "uuid",
  "fbResponse": { "events_received": 1 }
}

Números A/B

GET /api/sites/:siteId/numbers

Lista os números de WhatsApp configurados para distribuição A/B.

Resposta 200

[
  {
    "id": "uuid",
    "siteId": "abc123",
    "number": "5511999990000",
    "label": "Vendedor A",
    "weight": 70,
    "createdAt": "2024-01-10T10:00:00.000Z"
  }
]
POST /api/sites/:siteId/numbers

Adiciona um número ao pool de distribuição A/B.

Body application/json

CampoTipoObrig.Descrição
numberstringsimNúmero com DDI+DDD (ex: 5511999990000)
labelstringnãoIdentificação (ex: "Vendedor A")
weightnumbernãoPeso relativo. Padrão: 50

Resposta 200

Retorna o objeto do número criado (mesmo formato do GET).

DELETE /api/sites/:siteId/numbers/:numberId

Remove um número do pool A/B.

Resposta: {"ok": true}

GET /api/sites/:siteId/numbers-stats

Retorna cliques, conversões e taxa de conversão por número de WhatsApp.

Resposta 200

[
  {
    "number": "5511999990000",
    "cliques": 210,
    "conversoes": 18,
    "taxa": 9
  },
  {
    "number": "5511988880000",
    "cliques": 90,
    "conversoes": 6,
    "taxa": 7
  }
]

Ordenado por cliques (decrescente). taxa é a porcentagem inteira.
